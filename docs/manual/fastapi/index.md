## How to Use This Section

- Canonical path note: prefer `fastapi/basics/` when `fastapi/basic/` duplicates exist.
- Learning path: `basics/getting_started.md` -> CRUD -> dependencies -> best practices -> troubleshooting -> `security/jwt.md` -> `advanced/`.
- Review loop: re-read dependencies, best practices, troubleshooting, and JWT notes before building a new API.
